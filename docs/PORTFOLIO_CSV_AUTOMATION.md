# 保有株CSV自動化の現状

## 既存のadapter境界

`services.marketspeed_import` が楽天証券マーケットスピード専用CSVを担当する。UTF-8 BOM / UTF-8 / CP932を判定し、銘柄コードを正規化し、口座区分ごとの重複行を集約したうえで、必ずpreviewを経由して取り込む。

previewで扱う更新方針は `update` / `skip` / `new_only` の3つ。不明列・不正行・不正数値はfail-closedで行単位にエラー化し、正常行の処理を継続する。CSVに存在しない既存保有株は自動で非保有へ変更しない。

## 保持するデータ

取り込みで更新するのは会社名、保有区分、株数、平均取得価額、生成した口座内訳メモだけ。買い検討価格、ユーザーメモの既存行、ニュースキーワード、決算、関連銘柄、企業カルテの市場・業種・略称は保持する。現在値、評価損益、PER、PBR、決算日は正式データへ保存しない。

## 現在の証跡とHuman Action

- 自動テストで文字コード、数値、重複口座集約、preview非変更、部分エラー継続、更新/スキップ/新規方針、既存データ保持を確認済み。
- 未確認: 実際の楽天マーケットスピードCSVを実画面から取り込むこと、口座内訳とCSVにない保有株候補を人間が確認すること。
- 実データ確認前に既存保有株を削除・非保有化しない。自動売買・注文発注は対象外。
