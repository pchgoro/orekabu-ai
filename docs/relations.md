# 関連銘柄

対応バージョン: v0.2.0

## 目的

自分の銘柄を確認するきっかけになり得る関連企業の決算予定を整理します。影響を断定する機能ではありません。

## 関係の方向

`影響を受ける銘柄 ← 関連銘柄` の方向で1件を保存します。双方向関係は逆向きのレコードも登録します。

例: `住友電工 ← 古河電工`、関係タイプ「同業」、影響度「中」。

## 選択肢

relation_typeは、同業、顧客、仕入先、競合、親会社、子会社、テーマ関連、海外関連、指数関連、その他です。impact_levelは高、中、低です。

## 決算影響表示

関連銘柄の次回決算日、残り日数、四半期を、自分の銘柄とともに表示します。並び順は決算日の近さ、影響度、保有株優先です。

## CSV

列は `source_ticker,related_ticker,relation_type,impact_level,memo` です。UTF-8 BOM付きで出力し、既存の関係は更新またはスキップを選択できます。
