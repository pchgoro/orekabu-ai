# 今日のブリーフィング

トップ画面だけで毎朝の確認対象を把握するためのルールベース表示です。売買推奨ではありません。上部は「今日やること」「重要イベント」「最新材料」の3ブロックです。

## 集計

本日・7日以内の決算、決算候補、今日・未読・重要・お気に入りニュース、買い検討ライン、注目スコア、株価取得失敗、RSS取得失敗を表示します。RSS最終取得日時は件数とは別に表示します。

## 今日やること

本日決算、3日以内の決算、競合・日付変更候補、買い検討ライン到達、重要未読ニュース、保有株未読ニュース、注目スコア上位、RSS失敗の順で最大10件を生成します。同順位では元データの表示順を維持します。

戦略タグ・共通ルールでは、損切到達、利確到達、同順位競合、保有株のルール未設定を既存優先順位へ追加します。損切・利確到達は企業カルテへ、複数の未設定銘柄は戦略・カテゴリ画面へ移動します。個別上書きはタグ候補より優先し、競合を自動適用しません。

優先度1〜3は「今すぐ見る」、4〜7は「今日見る」、8以降は「あとで見る」と表示します。

## 詳細セクション

保有株、決算、ニュース、適時開示、自動取得状況は折りたたみ表示です。重要情報を先にし、詳細は必要なときだけ開きます。

## 設定

標準・コンパクト、表示密度、ブリーフィング件数、今日やること件数、0件項目の非表示を設定できます。
