# 今日のブリーフィング

トップ画面だけで毎朝の確認対象を把握するためのルールベース表示です。売買推奨ではありません。

## 集計

本日・7日以内の決算、決算候補、今日・未読・重要・お気に入りニュース、買い検討ライン、注目スコア、株価取得失敗、RSS取得失敗を表示します。RSS最終取得日時は件数とは別に表示します。

## 今日やること

本日決算、3日以内の決算、競合・日付変更候補、買い検討ライン到達、重要未読ニュース、保有株未読ニュース、注目スコア上位、RSS失敗の順で最大10件を生成します。同順位では元データの表示順を維持します。

## 設定

標準・コンパクト、ブリーフィング件数、今日やること件数、0件項目の非表示を設定できます。
