# モバイル表示

## 方針

狭い画面では重要情報を先にし、metricは最大2列、操作ボタンは十分な高さと横幅を確保します。長いタイトルとURLは折り返します。

## モバイル優先表示

保有株、監視銘柄、決算、ニュース、適時開示、企業カルテは主要情報をカード優先で表示します。設定を有効にすると複数列部分も縦構成へ切り替えます。Streamlitだけではサーバー側のviewportを確実に判定できないため、表示方式は利用者が明示的に選択します。

カードでも状態ラベルを文字で表示し、色だけに依存しません。詳細情報は展開して確認できます。

## 表示密度

コンパクト、標準、ゆったりの3段階です。カード内の余白だけを変更し、表示する情報や保存データは変更しません。

## 共通表示

- ボタンは390px幅で高さ44px以上
- metricは1〜2列を優先
- 長いタイトルとURLは折り返し
- 横長テーブルはコンパクト表示を除きカードを優先
- 赤は上昇・利益・プラス・好材料、緑は下落・損失・マイナス
- 黄は決算接近・要確認・警告、青は情報・ニュース・適時開示、灰は未設定・対象なし
- ダークモードでも騰落値と状態ラベルが背景へ埋もれない明度を使用
