# 適時開示管理

## 目的

保有株・監視銘柄の適時開示を手動で整理し、一次資料と確認事項へ短時間で到達するための機能です。関連性や売買判断を断定しません。

## 登録方法

「適時開示」ページで登録済み銘柄、種別、タイトル、日時、出典、公開URL、PDF URL、要約、重要度、タグ、メモを入力します。PDF添付は`data/disclosures`へ保存され、DBにはパスだけが記録されます。既存PDFを参照する場合も同ディレクトリ配下に置きます。

## 重複排除

`external_id`、`document_url`、`source_url`、最後に`ticker + title + disclosed_at`の順で材料を選び、SHA-256の`content_hash`を作ります。CSVでは重複を更新またはスキップできます。

## ニュース連携

URL一致または十分に長いタイトル包含で候補を作成します。候補は`confirmed=0`で、自動確定されません。画面から承認または手動関連付けします。

## セキュリティ

- 公開HTTP(S)以外のURLを拒否
- file URL、localhost、非公開IP、認証情報付きURLを拒否
- PDF以外、PDF署名がないファイル、10MB超を拒否
- 解決後パスが`data/disclosures`外なら拒否
- HTMLタグと制御文字を保存前に除去
- CSV数式として評価される文字列を出力時に無害化

## 制限事項

TDnet自動巡回、PDF本文解析、XBRL解析、AI要約、定期取得、通知は実装していません。開示内容は必ず企業の一次資料で確認してください。
