# 決算日候補取得

## 目的

登録銘柄の次回決算予定日を外部ソースから候補として取得し、未登録・変更・競合・取得失敗を確認しやすくします。売買判断や正式日付の自動決定は行いません。

## 取得から承認まで

1. ユーザーが対象を選び「決算候補を取得」を押す
2. プロバイダーが取得結果を共通形式へ正規化する
3. 既存の手動決算と比較する
4. `earnings_candidates`へ候補として保存する
5. ユーザーが変更前後を確認する
6. 承認時だけ正式な`earnings_events`へ反映する

外部情報の誤りや予定変更から手動データを守るため、自動上書きは禁止しています。

## プロバイダー方式

共通の`EarningsProvider`契約を使用します。現在の外部取得はyfinanceのみで、CSV取込も同じ候補結果へ正規化します。固有仕様はプロバイダー内へ隔離します。

## yfinanceの制限

空データ、過去日、複数候補、時刻なし、四半期不明、仕様変更、レート制限があり得ます。信頼度は低として保存し、取得失敗は銘柄単位で記録します。

## 候補状態

確認状態はpending、approved、rejected、heldです。比較状態はnew、same、date_changed、time_changed、quarter_changed、conflict、past_date、invalid、unknownです。

## 承認操作

新規登録、既存予定の更新、日付・時刻・四半期だけの更新、既存維持を選べます。確定データの変更には追加確認が必要です。承認処理はトランザクションで実行します。

## CSV候補取込

`ticker,earnings_date,announcement_time,fiscal_year,fiscal_quarter,source_name,source_reference,confidence,memo`をUTF-8 BOMで扱います。正式イベントへ直接登録しません。

## エラー処理

ネットワーク、空データ、不正日付、存在しないticker、重複、DB失敗を日本語で表示し、技術詳細をログへ記録します。一銘柄の失敗で一括処理を停止しません。

## 将来

TDnet、EDINET、定期実行は未実装です。追加時も候補保存と人間承認を維持し、アクセス制限や認証を回避しません。
