# 決算管理

対応バージョン: v0.2.0以降

## 目的

登録銘柄の決算予定と確認時期を整理する機能です。売買を推奨しません。

## 手動登録

決算管理ページで銘柄、対象年度、四半期、決算日、発表時間、日付状態、メモを入力します。日付不明の場合は「未確認」として日付なし（NULL）で保存できます。「予定」または「確定」では決算日が必須です。同じ銘柄・年度・四半期は1件だけです。

## 状態と残り日数

日本時間の今日を基準に、今日、明日、直前、今週、2週間以内、1か月以内、先予定、発表済み、日付未確認を表示します。日数は営業日ではなくカレンダー日数です。

## CSV

列は `ticker,fiscal_year,fiscal_quarter,earnings_date,announcement_time,date_status,memo` です。UTF-8 BOM付きで出力します。既存キーは更新またはスキップを選択できます。

## 制限事項

決算候補は次の順で取得します。

1. yfinance
2. yfinanceで将来日がない銘柄だけ、登録済み企業公式IRカレンダー/IRニュース
3. JPX上場会社情報の手動確認
4. 未取得として記録

企業公式IR URLは決算自動取得画面の「IR情報源」で銘柄ごとに登録します。取得処理はrobots.txtを確認し、同一ページを24時間以内に再取得しません。HTML全文は保存せず、候補日、URL、取得日時、短い根拠、confidenceだけを`earnings_candidates`へ保存します。

対応する日付表現は`YYYY年M月D日`、`YYYY/MM/DD`、`YYYY-MM-DD`、`YYYY.MM.DD`、文脈から年を判定できる`M月D日`です。過去日は候補化しません。四半期と年度は明示表現がある場合だけ推定します。

画像のみのカレンダー、JavaScriptで後から描画される日程、「8月中旬」のように日が確定していない表現は保存しません。会社別専用パーサーは汎用抽出で対応できない場合だけ検討します。月間カレンダーは日付グループ一覧です。

自動取得結果は正式決算へ自動反映されません。利用者が候補を承認した場合だけ新規登録または更新します。
