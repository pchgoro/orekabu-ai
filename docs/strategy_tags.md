# 戦略タグ

## 目的

1銘柄へ複数のテーマ、投資スタイル、保有期間、戦略、独自カテゴリを付与し、銘柄横断で確認するための分類です。タグは売買推奨や自動判定ではありません。

## グループ

- `theme`: AI、半導体、電力、データセンター、防衛、宇宙、ロボット
- `style`: グロース、バリュー、高配当、優待
- `horizon`: 短期、中期、長期
- `strategy`: 押し目買い、決算跨ぎ、イベント投資、積立
- `custom`: 利用者が追加する独自分類

同じ名前でもグループが異なれば別タグです。CSVはタグ名だけを持つため、同名タグが複数グループにある場合は曖昧な行として取込を拒否します。

## 管理

タグは作成、編集、有効化、無効化、未使用時の削除ができます。関連銘柄やルールがあるタグは削除せず、無効化を優先します。銘柄への割当は複数選択、一括割当、一括解除、CSVに対応します。

## 集計

タグごとに銘柄数、保有評価額、評価損益、平均損益率、ポートフォリオ比率、7日以内決算、未読ニュース、重要開示、損切・利確接近件数を表示します。1銘柄を複数タグへ計上するため、全タグ合計はポートフォリオ合計を超える場合があります。

## CSV

UTF-8 BOM付きで入出力します。

```text
ticker,tags
5801.T,AI|電力|中期|高配当
```
