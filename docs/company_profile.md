# 企業カルテ

## 目的

登録企業の株価、決算、ニュース、適時開示、関連銘柄を一画面へ集約し、確認先を探す操作を減らします。企業カルテは情報整理用で、売買判断を代行しません。

## 検索と基本情報

ticker、会社名、任意登録した略称で検索します。市場、業種、略称は手動入力で、外部マスタから自動取得しません。保有状態、分類、保有メモは既存の銘柄データを使用します。

## 集約範囲

- 既存yfinance処理による株価概要と注目スコア
- 次回決算、決算候補、関連企業の決算、過去決算
- 承認済み銘柄関連ニュースの最新5件と状態件数
- 適時開示の最新5件と状態件数
- EDINET書類メタデータの最新5件
- 入力・出力方向を明示した関連銘柄
- 手動テーマ、投資ストーリー、確認チェックリスト
- 買った理由、段階利確、損切り、保有予定、売却条件を含む投資ルール
- 複数の戦略タグ、適用中の共通ルール、損切・利確・買い増しライン、個別上書き
- 日付付きユーザーメモ
- ニュース、適時開示、決算、EDINET、メモの新しい順タイムライン

横断処理は`services/company_profile.py`に集約し、画面から各サービスを個別に組み合わせません。

## プロンプト

基本情報、株価、次回決算、最新ニュース、最新開示、EDINET、関連銘柄、テーマ、投資ストーリー、投資ルール、戦略タグ・共通ルール、チェックリスト、メモをコピー用テキストへ整形します。AI APIは呼び出しません。事前ルールを前提に事実、推測、リスクを分け、売買を断定しない指示を含みます。

## UI

株価・保有状況、今日の注意点、投資ルール、次回決算、最新ニュース、最新適時開示、EDINET・関連銘柄、メモ、ChatGPTプロンプトの順に確認できます。投資ルールでは現在値、次の利確ライン、損切りラインとの距離を表示し、詳細は企業カルテ内だけで編集します。通常は2〜3列です。設定の「モバイル優先表示」を有効にすると縦並びになります。ブラウザ幅の自動判定は行いません。

## 制限事項

市場・業種の自動更新、テーマ自動分類、AI分析、過去チャート、ポートフォリオ影響は将来候補です。株価取得に失敗しても、DB内の決算・ニュース・開示・EDINET・関連銘柄・ユーザー記録は表示します。
