# ニュースソース

## 対応形式

RSS 2.0とAtomの標準的な要素をPython標準ライブラリで解析します。ソースには名前、種別、URL、有効状態、メモを保存します。

## 取得動作

有効なRSS/Atomを一件ずつ処理します。一つのソースが失敗しても他のソースを継続し、実行集計とソース別結果をDB・ログへ記録します。利用者は各配信元の利用条件を確認してください。
高頻度アクセスと一度の大量保存を避けるため、1ソースの1回取得は先頭5件までに制限します。

## CSV

ソースCSVは `name,source_type,url,is_enabled,memo` です。RSS/AtomにはHTTPまたはHTTPS URLが必要です。

## 制限

ETag、Last-Modified、認証付きフィード、JavaScript生成ページ、Webスクレイピングには対応しません。
